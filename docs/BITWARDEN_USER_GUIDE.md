# Bitwarden — как пользоваться (для новичков)

Bitwarden — это **менеджер паролей**. Вы храните логины и пароли в зашифрованном «сейфе». Доступ — по **одному главному паролю** (master password).

Ваш сервер: **https://huitawarden.bttsrvvrs.org**

---

## 1. Установите приложение

Скачайте официальный **Bitwarden** (не сторонние форки):

| Платформа | Где взять |
|-----------|-----------|
| Windows / macOS / Linux | https://bitwarden.com/download/ |
| Android / iOS | App Store / Google Play — «Bitwarden» |
| Браузер | Расширение «Bitwarden» в Chrome / Firefox / Edge |

---

## 2. Укажите свой сервер (важно!)

По умолчанию Bitwarden подключается к облаку bitwarden.com. У вас **свой** сервер.

**В приложении или расширении:**

1. На экране входа нажмите **⚙ Settings** (или «Настройки»).
2. **Self-hosted environment** / «Собственный сервер».
3. **Server URL:** `https://huitawarden.bttsrvvrs.org`
4. Сохраните.

**В мобильном приложении:** Settings → Self-hosted → Server URL.

Без этого шага вход не сработает — приложение будет стучаться не туда.

---

## 3. Создайте аккаунт

1. Откройте https://huitawarden.bttsrvvrs.org
2. **Create account** / «Создать аккаунт»
3. Email + **Master password** (главный пароль)

### Про главный пароль

- Это **единственный** пароль, который нужно помнить.
- Его **нельзя восстановить** — если забудете, доступ к сейфу потерян навсегда.
- Сделайте длинную фразу, например: `correct horse battery staple 2026!`
- Запишите на бумаге и спрячьте дома (не в облако).

После регистрации войдите тем же email и master password.

---

## 4. Ежедневное использование

### Сохранить пароль

1. В приложении: **+** → **Login** (или «Вход»).
2. Заполните:
   - **Name** — название (GitHub, Gmail…)
   - **Username** — логин или email
   - **Password** — пароль (можно сгенерировать 🎲)
3. **Save**

### Вставить пароль на сайте

1. Установите **расширение** в браузер и войдите в аккаунт.
2. Зайдите на сайт (например, почта).
3. На поле логина/пароля появится иконка Bitwarden — нажмите → выберите запись → **Autofill**.

Или: правый клик по полю → Bitwarden → нужная запись.

### Сгенерировать сильный пароль

В записи или в расширении: **Generator** → длина 20+, буквы+цифры+символы → **Copy** / вставить в форму регистрации на сайте → сохранить в Bitwarden.

---

## 5. Синхронизация

Все устройства с одним аккаунтом и URL `https://huitawarden.bttsrvvrs.org` видят **один и тот же сейф**:

- Добавили пароль на телефоне → через секунду видно на ПК.
- Данные хранятся на **вашем VPS**, не у Bitwarden Inc.

---

## 6. Двухфакторная аутентификация (2FA) — рекомендуется

Защита сейфа, если кто-то узнает master password:

1. https://huitawarden.bttsrvvrs.org → **Settings** → **Security** → **Two-step login**
2. Включите **Authenticator App** (Google Authenticator, Aegis и т.п.)
3. Отсканируйте QR-код телефоном.

При входе кроме пароля попросят 6-значный код из приложения.

---

## 7. Типы записей

| Тип | Для чего |
|-----|----------|
| **Login** | Сайты, приложения (логин + пароль) |
| **Secure Note** | Текст без полей (номера карт заметки, seed-фразы) |
| **Card** | Банковские карты |
| **Identity** | ФИО, адрес, паспорт (для автозаполнения форм) |

## 9. Частые вопросы

**Забыл master password**  
Восстановить нельзя. Это by design — даже админ сервера не видит ваши пароли.

**«Invalid master password»**  
Проверьте раскладку клавиатуры и Caps Lock. Убедитесь, что Server URL = `https://huitawarden.bttsrvvrs.org`.

**Расширение не предлагает автозаполнение**  
Войдите в расширение, обновите страницу, проверьте что URL сайта совпадает с записью (домен в поле URI).

**Нужен интернет?**  
Да, для синхронизации с вашим сервером. На телефоне можно включить **Unlock with PIN / биометрию** для быстрого доступа к уже загруженному сейфу.

**Чем отличается от «просто записать в блокнот»?**  
Пароли зашифрованы, генерируются уникальные, автозаполнение без копипаста, один сейф на всех устройствах.
