# Быстрый старт — оператор (v1)

> Краткая инструкция для ежедневной работы. Полное руководство: [`README.md`](README.md).

## 1. Вход

1. Откройте адрес приложения (например `https://app.<ваш-домен>`).
2. Введите email и пароль.
3. После входа откроется список чатов.

## 2. Ответ в чате

1. Откройте чат.
2. Прочитайте контекст (последние сообщения и карточку контакта).
3. Напишите ответ и отправьте.
4. При необходимости смените **статус** диалога (например «в работе» → «закрыт»).

### Сделки (лиды)

В CRM **одна сделка** — это **лид** по клиенту в вашей группе.

| Действие | Что происходит |
|----------|----------------|
| Клиент пишет в чат | Сообщения привязываются к **открытому** лиду (текущая сделка). |
| Сделка завершена | **Закройте лид** — кнопка в шапке чата или в карточке лида; воронка перейдёт в финальный этап. |
| Клиент пишет **снова** после закрытия | Создаётся **новый** лид (новая сделка); старая переписка остаётся в истории с прежним `lead_id`. |

В карточке контакта счётчик «были сделки» (`prior_leads_count`) учитывает **все** закрытые лиды по клиенту в организации; список сделок в API — только **вашей** группы.

Метка «новый / постоянный клиент» у чата — отдельно от воронки сделки. Подробнее: [`../LEADS.md`](../LEADS.md).

### Файлы

- Прикрепите документ или изображение кнопкой **«Скрепка»** или перетащите файл в окно чата.
- Дождитесь загрузки — сообщение появится после обработки хранилища.

## 3. Фильтры списка чатов

- Статус диалога, бот, непрочитанные, назначение.
- **Только с открытой сделкой** — чаты, у которых есть активный лид.
- Глобальный поиск: **Ctrl+K**.

## 4. Карточка контакта

- Откройте контакт из чата или раздела «Контакты».
- Вкладка **Сделки** — история лидов вашей группы.
- Редактируйте разрешённые поля; смотрите историю изменений.

## 5. Передача карточки

1. **Передать карточку** — коллега в той же группе.
2. При необходимости старший подтверждает.
3. Получатель принимает в inbox передач.

## 6. Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| Ctrl+K | Глобальный поиск |
| Ctrl+Enter | Отправить сообщение (если включено) |

Тема (светлая / тёмная) — в шапке приложения.
