## Sample: inbound `bot-events` (для шага 14)

Выполняет **интегратор бота** или DevOps с `inbound_secret` зарегистрированного бота. Подпись — по [`docs/BOTS_INTEGRATION.md`](../../docs/BOTS_INTEGRATION.md) §3.

Минимальный envelope (подставьте `bot_code`, `event_id`, контакт):

```json
{
  "event": "message.received",
  "event_id": "uat-01J5G4SMOKE0001",
  "occurred_at": "2026-05-17T12:00:00Z",
  "bot_code": "support_a",
  "payload": {
    "contact": {
      "telegram_user_id": 900001001,
      "first_name": "UAT",
      "last_name": "Client"
    },
    "message": {
      "external_id": "uat-msg-001",
      "text": "UAT: тестовое входящее с staging",
      "attachments": [],
      "sent_at": "2026-05-17T12:00:00Z"
    }
  }
}
```

`POST https://api.<DOMAIN>/api/v1/bot-events` с заголовками `X-Bot-Code`, `X-Bot-Timestamp`, `X-Bot-Event-Id`, `X-Bot-Signature`.

> Если бот на staging ещё не подключён — шаг 14 помечают **N/A** с ссылкой на дату подключения бота.
